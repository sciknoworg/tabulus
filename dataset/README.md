# Dataset

This directory contains the complete evaluation dataset used for benchmarking the scientific table extraction and bibliography-aware reference matching pipeline.

The dataset was manually curated during the thesis work and contains scientific papers together with OCR extraction outputs, bibliography extraction results, DOI matching results, and evaluation metrics.

---

# Dataset Availability

The complete dataset exceeds **700 MB** and therefore cannot be uploaded directly to GitHub.

The dataset can be accessed using the following external link:

```text
https://zenodo.org/records/20230340
```

# Ref Directory

The `Ref/` directory contains bibliography extraction results and evaluation files.

Example:

```text
Ref/
│
├── chandra_ref_raw_P51.txt
├── deepseek_ref_raw_P51.txt
├── kreuzberg_ref_raw_P51.txt
├── paddle_ref_raw_P51.txt
│
├── extracted_kreuzberg_ref.json
├── gold_standard_references.json
├── grobid_prediction.json
│
├── grobid_f1_score_result.json
├── grobid_fuzzy_f1_score_result.json
├── kreuzberg_plus_regex_f1_score_result.json
├── reference_eval_results.json
```

## Description

| File | Description |
|---|---|
| `gold_standard_references.json` | Manually created bibliography ground truth |
| `grobid_prediction.json` | References extracted using GROBID |
| `extracted_kreuzberg_ref.json` | References extracted using Kreuzberg OCR + regex |
| `*_ref_raw_*.txt` | Raw OCR text extracted from bibliography pages |
| `*_f1_score_result.json` | Precision, recall, and F1-score evaluation |
| `reference_eval_results.json` | Aggregated evaluation results |

# Ref_Tables Directory

The `Ref_Tables/` directory contains table extraction outputs and prediction results generated by different OCR models.

Example:

```text
Ref_Tables/
│
├── chandra_prediction/
├── deepseek2_prediction/
├── Kreuzberg_prediction/
├── paddle_vl_prediction/
│
├── gold_standard.csv
├── minerU_extracted_table.png
└── results/
```

## Description

| Directory / File | Description |
|---|---|
| `gold_standard.csv` | Ground truth table |
| `minerU_extracted_table.png` | Table crop generated by MinerU |
| `paddle_vl_prediction/` | PaddleOCR-VL extraction results |
| `deepseek2_prediction/` | DeepSeek OCR extraction results |
| `chandra_prediction/` | Chandra OCR extraction results |
| `Kreuzberg_prediction/` | Kreuzberg OCR extraction results |
| `results/` | Evaluation outputs and processed files |

# Purpose

The dataset was created for evaluating:

- scientific table extraction,
- OCR robustness,
- bibliography extraction,
- DOI enrichment,
- reference matching,
- reference-aware table processing pipelines.

---

# Notes

The dataset contains both intermediate and final processing outputs to improve reproducibility and allow detailed inspection of the extraction pipeline.

Some OCR outputs and benchmark files are intentionally preserved to support future comparison experiments and reproducibility of the evaluation.
