# Installation And Setup

Choose the setup path that matches the machine where you will run Tabulus.
CPU-only and Windows users can use the MinerU `pipeline` backend. GPU-server
users can use MinerU `hybrid-engine` and adapter-specific reconstruction
environments when suitable CUDA hardware is available.
