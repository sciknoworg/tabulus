# ocr_tables.json

`tables/ocr_tables.json` records structured table OCR results.

```json
{
  "success": true,
  "tables_found": 1,
  "tables": [
    {
      "table_id": 1,
      "source_file": "page_003_table_001.png",
      "n_rows": 2,
      "n_cols": 2,
      "rows": [["Reference", "Value"], ["[1]", "A"]],
      "source": "html"
    }
  ]
}
```
