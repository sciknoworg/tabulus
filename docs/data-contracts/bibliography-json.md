# bibliography.json

`references/bibliography.json` records normalized bibliography entries.

```json
{
  "bibliography_count": 1,
  "bibliography_source": "grobid",
  "entries": [
    {
      "index": 1,
      "raw": "Smith J. Example paper. 2020.",
      "doi": "10.1234/example",
      "source": "grobid"
    }
  ]
}
```
