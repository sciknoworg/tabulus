# PaddleOCR Service

## Overview

This folder contains the PaddleOCR-VL based OCR service used in the scientific PDF processing pipeline.

The service is responsible for:

* OCR processing of extracted table images,
* extraction of structured table rows and columns,
* optional full PDF OCR processing,
* reference section OCR extraction,
* conversion of OCR output into structured JSON data.

The service exposes a FastAPI API and runs inside Docker with GPU acceleration.

---

# Purpose in the Pipeline

The PaddleOCR service is used after MinerU table detection.

Pipeline position:

```text
Scientific PDF
        ↓
MinerU Service
        ↓
Extracted table PNG crops
        ↓
PaddleOCR Service
        ↓
Structured table rows and cells
        ↓
Reference matching
```

The main purpose of this service is to transform table images into machine-readable structured data.

# OCR Pipeline Workflow

## 1. MinerU Extracts Table PNGs

The MinerU service extracts table crops from scientific PDFs.

Example output:

```text
page_003_table_001.png
page_005_table_002.png
```

---

## 2. Backend Sends Images to PaddleOCR

The backend uploads all cropped PNG files to:

```text
POST /ocr/images
```

---

## 3. PaddleOCR-VL Performs OCR

The service loads the PaddleOCR-VL model:

```python
pipeline = PaddleOCRVL()
```

The model performs:

* layout recognition,
* OCR text extraction,
* table structure recognition,
* markdown generation.

---

## 4. HTML or Markdown Tables are Parsed

The OCR output may contain:

* HTML tables,
* markdown tables,
* raw markdown text.

The service automatically converts them into:

```python
rows: List[List[str]]
```

---

## 5. Structured JSON Output is Returned

Example:

```json
{
  "table_id": 1,
  "source_file": "page_003_table_001.png",
  "n_rows": 5,
  "n_cols": 3,
  "rows": [
    ["Author", "Year", "DOI"],
    ["Smith", "2020", "10.xxxx"]
  ]
}
```

```text
GET /health
```

```json
{
  "ok": true

```

---

# `/ocr/images`

Processes extracted table PNG files.

Input:

```text
multipart/form-data
```

Output:

```json
{
  "success": true,
  "tables_found": 4,
  "tables": [...]
}
```

This endpoint is the primary OCR endpoint used by the pipeline.

---

# `/ocr/pdf`

Processes complete PDF files page-by-page.

The endpoint:

* renders PDF pages as images,
* runs OCR on every page,
* extracts tables,
* combines markdown output,
* returns OCR results.

This endpoint is mainly used for debugging and experimentation.

---

# `/ocr/references`

Processes bibliography pages.

The endpoint:

1. renders bibliography pages,
2. performs OCR,
3. extracts raw text,
4. applies heuristic reference splitting.

Output:

```json
{
  "success": true,
  "raw_text": "...",
  "references": [...]
}
```

---

# Table Extraction Logic

The OCR output generated by PaddleOCR-VL may contain HTML tables such as:

```html
<table>
<tr><td>Author</td><td>Year</td></tr>
</table>
```

The service parses these tables into:

```python
[
  ["Author", "Year"]
]
```

---

# HTML Table Parsing

The service includes a custom HTML parser:

```python
class _SimpleTableHTMLParser(HTMLParser)
```

This parser:

* reads `<tr>`, `<td>`, and `<th>` elements,
* extracts cell text,
* reconstructs table rows.

---

# Markdown Table Parsing

If no HTML tables are detected, markdown tables are parsed instead.

Example markdown:

```md
| Author | Year |
|---|---|
| Smith | 2020 |
```

Converted result:

```python
[
  ["Author", "Year"],
  ["Smith", "2020"]
]
```

---

# PDF Rendering

The service uses PyMuPDF (`fitz`) to render PDF pages into images before OCR.

Example:

```python
render_pdf_page_to_image()
```

The rendered images are processed with:

```text
200 DPI
```

---

# Reference Extraction

The service contains heuristic-based reference extraction logic.

It supports:

* numbered references,
* author-year references,
* DOI continuation cleanup,
* bibliography heading detection,
* multi-line reference reconstruction.

# Dockerfile

```dockerfile
FROM paddlepaddle/paddle:3.3.0-gpu-cuda11.8-cudnn8.9

ENV DEBIAN_FRONTEND=noninteractive
WORKDIR /app

RUN apt-get update && apt-get install -y \
    python3-pip \
    libgl1 \
    libglib2.0-0 \
    libgomp1 \
    && rm -rf /var/lib/apt/lists/*

RUN python3 -m pip install --upgrade pip

RUN python3 -m pip install --no-cache-dir -U "paddleocr[doc-parser]"

RUN python3 -m pip install --no-cache-dir \
    fastapi \
    uvicorn \
    python-multipart \
    pymupdf \
    pillow \
    requests

COPY api.py /app/api.py

EXPOSE 8000

CMD ["uvicorn", "api:app", "--host", "0.0.0.0", "--port", "8000"]
```

# Notes

This service focuses on structured OCR extraction for scientific tables.

The OCR output is later enriched by the backend through:

* reference table classification,
* DOI matching,
* GROBID integration,
* Crossref enrichment,
* bibliography resolution.

The service itself only performs OCR and table reconstruction.
